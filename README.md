# 💳 Credit Card Financial Dashboard – Power BI Project

## 📌 Project Overview

The **Credit Card Financial Dashboard** is an interactive business intelligence project developed using **Power BI and MySQL** to analyze credit card transactions, customer demographics, spending behavior, and financial performance.

The main objective of this project is to transform raw credit card transaction data into meaningful business insights through interactive dashboards and data visualizations. It helps stakeholders understand customer behavior, monitor revenue trends, and evaluate credit card business performance.

## 🎯 Project Objectives

- Analyze overall credit card transaction performance.
- Monitor revenue and transaction trends.
- Understand customer demographics and spending patterns.
- Identify revenue contributions across different card categories.
- Analyze customer acquisition and usage behavior.
- Provide actionable insights to support business decisions.

## 🛠️ Tools & Technologies Used

| Tool | Purpose |
|---|---|
| Power BI | Dashboard development and visualization |
| MySQL | Database management and data storage |

## 🗄️ Database & Data Processing

MySQL was used to store and manage the credit card transaction and customer datasets.

The project involved:

1. Importing raw CSV datasets into MySQL.
2. Creating and managing database tables.
3. Cleaning and preparing data for analysis.
4. Connecting MySQL data with Power BI.
5. Building relationships between customer and transaction tables.
6. Creating DAX measures and calculated columns.
7. Developing interactive dashboards.
